# Technology — nfpm 2.x (packaging)

- Version: 2.x (resolve exact at first package build, M5; verify then per Rule 5.2).
- Why: single YAML → `.deb` + `.rpm`, zero-dep Go binary, CI-friendly (decision 0001/Q2).
  `lintian` + `rpmlint` gates catch non-compliance.
- Used: `packaging/nfpm.yaml` + `systemd/` + `scripts/` (postinst/prerm never touch DB).
- **M4-C4 contract:** `nfpm.yaml` packages the app tree, the isolated
  `/opt/scriptorium/build-venv` generated by
  `scripts/build-venv.sh` from `build-requirements.lock`, the
  `config.env.example` (installed under `/usr/share/doc/scriptorium/`),
  and both systemd units. `postinst` seeds `/etc/scriptorium/config.env`
  0600 only when absent, creates `artifacts/`, and fails loud if the
  build venv is missing. The CI `packaging` gate pins these files and
  the Redis ordering; the actual signed package build remains M5.
- Verified: shortlist 2026-10-16 (goreleaser/nfpm); exact pin at M5 with matrix entry.
