## What changed

Published Sphinx artifacts now have a first-class serving surface, built
on the existing immutable build artifacts:

- **Publications (A2).** `athenaeums.latest_build_id` and
  `stable_build_id` are owner-selected pointers. `POST
  /api/v1/athenaeums/{id}/publish` accepts `{build_id, channel}` where
  `channel` is `latest`, `stable`, or `both`; `DELETE .../publish`
  clears pointers. Only `ok`, manifest-backed builds can be published;
  unpublish never revokes the immutable numbered build. First
  publication records `builds.published_at`/`published_by`. Audit:
  `build_published`, `build_unpublished`.
- **Visibility (B3).** `athenaeums.is_public` defaults to false.
  Private sites allow the owner or any member of a grimoire in the
  Athenaeum; outsiders get a uniform `404`. Public sites are anonymous.
  `PATCH /athenaeums/{id}` now accepts `is_public`.
- **Serving (C1/D1).** `app/routers/site.py` serves artifacts from
  `SC_ARTIFACT_ROOT` with a resolved-path jail:
  - `/a/{public_slug}/` → latest, else stable, else 404;
  - `/a/{public_slug}/latest/…` and `/stable/…` pointer aliases;
  - `/a/{public_slug}/b/{number}/…` immutable published builds;
  - slash-less roots and directories redirect to canonical URLs with a
    relative `Location` (query preserved; no Host-header echo) and
    private/no-store redirect headers for private sites.
  `public_slug` is a globally unique, immutable name separate from the
  per-owner editor slug; collisions get an 8-hex suffix (migration
  backfill uses the full UUID). Editor renames do not change public URLs.
- **Access cookie (B3 navigation).** Login/refresh set a 15-minute
  `scriptorium_access` HttpOnly, SameSite=Lax cookie scoped to `/a`
  (Secure in production); logout clears it. API routes still require
  bearer auth.
- **Manifest + E2 headers.** Successful builds write `manifest.json`
  beside `html/` with sorted file inventory/SHA-256, exact inline-script
  CSP hashes, site/build identity, and custom-CSS path/hash. The theme
  fails the build on inline `style` attributes, event handlers, or
  `<style>` blocks. Serving refuses artifacts without a valid manifest
  and emits `default-src 'none'` CSP with exact script hashes,
  `style-src 'self'`, no framing/objects/workers, plus nosniff,
  no-referrer, Permissions-Policy, X-Frame-Options, and same-origin
  COOP/CORP. Public numbered builds are one-year immutable; aliases are
  `no-cache`; private responses are `private, no-store`, `Vary: Cookie`,
  `X-Robots-Tag: noindex, nofollow`.
- **Custom CSS (E2).** `GET/PUT/DELETE /api/v1/athenaeums/{id}/custom-css`.
  Input and normalized file are capped at 64 KiB; selectors are rewritten under
  `html[data-sd-athenaeum]`; flat rules only; no at-rules, `url()`,
  `data:`, backslash escapes, `expression()`, `behavior`, or
  `position: fixed`. The build writes `_static/custom.css` as an
  external stylesheet and hashes it in the manifest. CSS changes require
  a rebuild; published artifacts never change.
- **Build/theme integration.** Sourcegen accepts `public_slug` and
  custom CSS, emits `site_id`, and sets `html_static_path`/`html_css_files`
  only when needed. The layout marks `data-sd-athenaeum`; the inline SVG
  sprite is hidden with `.sd-sprite` (no inline style). The runner
  writes the manifest only after a successful artifact copy.
- **Migration 0007.** Adds the public/visibility/pointer/CSS columns,
  backfills globally unique public slugs deterministically, and mirrors
  the additions on downgrade.

## Disclosures

- Public numbered builds are immutable-cached; if a site is later made
  private, copies already cached at public numbered URLs are outside the
  server's control. Treat publication as disclosure. Alias/private
  responses are not cacheable.
- `public_slug` allocation is check-then-insert; the unique constraint
  rejects a concurrent collision with a clean `409` rather than silently
  duplicating it or surfacing a 500. There is no public rename/alias flow
  in v1.
- Custom CSS has no at-rules (including `@media`), custom JavaScript,
  template overrides, or remote assets. The shipped theme's own
  responsive rules are unaffected.
- URL-durability aliases/redirects and distribution are later phases;
  the immutable public slug and numbered URLs are the base for them.
- The editorial app keeps its own CSP; E2 applies to published/served and
  exported artifacts.
