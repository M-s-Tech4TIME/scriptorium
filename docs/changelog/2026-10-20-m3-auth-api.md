# 2026-10-20 — Auth/session endpoints (M3 C2)

- `POST /api/v1/auth/login`, `/refresh`, `/logout` shipped
  (`backend/app/routers/auth.py`, decision 0018 Q-M3-1=A; users seeded by
  CLI only — no open registration).
- Refresh cookie `scriptorium_refresh`: HttpOnly, SameSite=Lax, path=/,
  7 d max-age; `Secure` toggled by `SCRIPTORIUM_COOKIE_SECURE` (prod
  packaging sets it). Access token returned in the JSON body.
- Wired to the M2 family store (0017): refresh rotates the cookie;
  reuse of any rotated-out cookie → 401 + whole-family burn as before;
  logout revokes the family (`reason=logout`) and clears the cookie.
- Enumeration guards: unknown email burns an argon2 dummy verify
  (`verify_dummy`); uniform 401 shape for both bad-password and
  unknown-email.
- Tests: `test_auth_api.py` (5 live-DB cases in CI — login validation,
  mint+rotation, reuse-burn chain, logout revocation, cookie-less
  refresh). Tests drive the app via `httpx.ASGITransport`
  (`starlette.testclient` import raises a Rule-6 deprecation warning).

- CI fix-up: fresh CI PG had no schema when test_auth_api.py ran
