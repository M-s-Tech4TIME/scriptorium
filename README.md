# Scriptorium — by M/s. Tech4TIME

Scriptorium: a self-hosted technical documentation platform built on Sphinx.
Write docs in a Word-like WYSIWYG editor instead of hand-writing RST or MyST;
Scriptorium converts, builds, and serves the site. Built for managing
documentation in depth, with clear structure and organization.
